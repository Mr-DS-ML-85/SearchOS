Your own index, your own API

Every query is answered from your Postgres — full-text (GIN tsvector) + vector (pgvector HNSW), fused with RRF, reranked, cached in Redis. Nothing leaves your infra. Ever.

Learns as you search

SearXNG is a live web fallback that persists every result into your index. The more you search, the more coverage you own. Repeat queries never touch the network.

Crawls while you sleep

Seed a URL or sitemap; the crawler follows same-domain links up to a configurable depth and keeps pages fresh with continuous recrawling. Dedupes by normalized URL.

MCP, all three ways

One server exposes search, extract, ingest, stats, health over stdio, legacy HTTP+SSE, and the new stateless Streamable HTTP (2026-07-28).

Try it in 30 seconds

bash
# boot the whole stack, web fallback included
docker compose --profile web up -d --build

# seed a page
curl -s -X POST http://localhost:8000/v1/admin/ingest \
  -H "Authorization: Bearer $ADMIN" -H "Content-Type: application/json" \
  -d '{"url":"https://en.wikipedia.org/wiki/Vector_database","kind":"url"}'

# search it — answered from YOUR index
curl -s "http://localhost:8000/v1/search?q=vector+database" \
  -H "Authorization: Bearer $ADMIN"
